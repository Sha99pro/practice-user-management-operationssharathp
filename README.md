# SQL User Management Operations Practice

## Overview
In this practice, I learned how to use SQL in MySQL Workbench to work with user data. I practiced adding, viewing, updating, and deleting users in the `testdb` database.

## Key Skills Practiced
- Adding new users using `INSERT`.
- Updating user information using `UPDATE`.
- Deleting users using `DELETE`.
- Finding users using `SELECT` and `WHERE`.
- Sorting results using `ORDER BY`.
- Limiting results using `LIMIT`.

## Challenges & Key Learnings
The most challenging part was understanding how to use the `WHERE` clause in `UPDATE` and `DELETE` queries. I learned that without `WHERE`, these queries can change or delete all rows in the table. This practice helped me understand how to write SQL queries and work with data in a database.
